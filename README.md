A Spring Boot based Employee Management System designed to practice JPA annotations such as @Entity, @Table, and @Column. The backend exposes REST APIs for managing employee records, while the frontend provides a simple interface to interact with the data. The project reinforces the Repository layer using Spring Data JPA and shows how to structure a Spring Boot application following layered architecture principles.

Tech Stack: Spring Boot, Spring Data JPA, MySQL, HTML, CSS, JavaScript
Learning Focus: JPA annotations, Repository layer, REST API design
